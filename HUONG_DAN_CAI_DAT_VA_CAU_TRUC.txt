1. TONG QUAN DU AN
- Ten he thong: WebGIS Giam sat va Du bao chi so thuc vat NDVI / LST / TVDI TP.HCM

  + Backend : FastAPI (Python 3.11+), SQLAlchemy, Rasterio, GeoPandas, Scikit-learn

3. HUONG DAN CAI DAT VA KHOI CHAY
--------------------------------------------------------------------------------
Yeu cau he thong:
- Python >= 3.11
- Node.js >= 18 (kem npm)
- Docker Desktop (hoac PostgreSQL >= 14 da cai san PostGIS)

=== CACH 1: KHOI CHAY NHANH BANG POWERSHELL SCRIPT (KHUYEN DUNG) ===
1. Mo terminal PowerShell tai thu muc: `ndvi-ai-web`
2. Chay script cai dat tu dong:
   .\setup.ps1
   (Script se tu kiem tra moi truong, tao venv, cai dat pip/npm, chay Docker DB, nap schema va du lieu)
3. Chay script khoi dong he thong:
   .\start.ps1
4. Truy cap ung dung:
   - Frontend WebGIS: http://localhost:5173
   - Backend API Docs: http://localhost:8000/docs

=== CACH 2: KHOI CHAY THU CONG (KHONG DUNG SCRIPT) ===
1. Co so du lieu:
   - Khoi dong container DB:
     docker-compose up -d
   - Hoac tao CSDL thu cong trong PostgreSQL voi ten `ndvi_ai`, bat extension PostGIS:
     CREATE EXTENSION postgis;
   - Chay script tao bang: chay file `database/schema.sql`

2. Backend (FastAPI):
   - Di vao thu muc: cd ndvi-ai-web/backend
   - Tao moi truong ao: python -m venv venv
   - Kich hoat venv:
     + Windows: .\venv\Scripts\activate
     + Linux/Mac: source venv/bin/activate
   - Cai thu vien: pip install -r requirements.txt
   - Chay backend: uvicorn app.main:app --reload --port 8000

3. Nap du lieu vao DB:
   - Di vao thu muc: cd ndvi-ai-web
   - Chay: python scripts/ingest_all.py

4. Frontend (React + Vite):
   - Di vao thu muc: cd ndvi-ai-web/frontend
   - Cai thu vien: npm install
   - Chay frontend: npm run dev
   - Mo trinh duyet: http://localhost:5173
